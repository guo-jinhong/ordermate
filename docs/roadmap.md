# Roadmap

本文只记录尚未完成的方向，不作为已交付能力声明。

## P0：上线演示前

- 完成一次 live DeepSeek 全链路人工验收并记录模型名、日期和结果。
- 验证商品查询、加购、修改数量、下单、支付和取消订单确认流。
- 在不暴露 Key、JWT 和个人数据的前提下录制演示视频。
- 完成 Docker 冷启动与重建测试。

## P1：可靠性

- 将 Redis 作为明确的可选部署组件加入标准编排，并测试服务重启恢复。
- 增加端到端测试与固定 Function Calling 评测集。
- 前端确认卡显示动作、旧值、新值、过期时间和失败原因。
- 增加工具调用耗时、结果条数与错误状态展示。
- 引入 Flyway 或 Liquibase 管理数据库变更。

## P1：可运维性

- 增加结构化指标、健康检查、监控和告警。
- 建立 MySQL 备份、恢复与升级回滚演练。
- 增加容器镜像版本固定和依赖安全扫描。
- 完成云服务器 HTTPS 部署验证。

## P2：知识能力

- 将 RAG 限定在售后、保修、退换货、FAQ 和产品手册。
- 为知识文档增加来源、版本、更新时间和权限控制。
- 结构化业务数据继续通过 Java API 和 MySQL 查询。

## P2：真实指标

- 工具选择准确率。
- 工具调用成功率。
- 首事件延迟与完整响应时间。
- 购物车和订单流程成功率。
- 基于业务事实的回答错误率。

任何对外展示的量化数字都应来自可重复测试，不使用估算或宣传性数字。
